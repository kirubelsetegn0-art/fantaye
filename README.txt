FANTAYE ANDROID APK - እንዴት መስራት
1. github.com ላይ በነጻ ይመዝገቡ -> New repository (ስም: fantaye)
2. "uploading an existing file" ን ይንኩ -> የዚህን ፎልደር ሁሉንም ፋይሎች (.github ፎልደርን ጨምሮ) ይጎትቱ -> Commit
3. Actions ትር -> "Build APK" -> ሲጨርስ (አረንጓዴ ምልክት) -> ከታች Artifacts -> Fantaye-APK ያውርዱ
4. zip ውስጥ app-debug.apk አለ -> ወደ ስልክ ይላኩ -> ይጫኑ (Install unknown apps ይፍቀዱ)
